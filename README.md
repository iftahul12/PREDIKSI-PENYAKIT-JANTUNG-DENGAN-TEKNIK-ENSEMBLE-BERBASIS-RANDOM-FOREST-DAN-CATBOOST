# Analisis Data dan Prediksi Menggunakan Machine Learning

## 📌 Tentang Project

Project ini merupakan tugas akhir yang berfokus pada analisis data dan penerapan Machine Learning untuk mengidentifikasi pola serta melakukan klasifikasi berdasarkan data kesehatan.

Dalam project ini, dilakukan proses pengolahan dan analisis terhadap dataset dengan lebih dari **300.000 data**. Tahapan yang dilakukan meliputi data preprocessing, eksplorasi data, penanganan ketidakseimbangan data, pembangunan model Machine Learning, serta evaluasi performa model.

Project ini tidak hanya mengembangkan kemampuan teknis, tetapi juga melatih kemampuan **analytical thinking, problem solving, ketelitian, dan pengambilan keputusan berdasarkan data**.

---

## 🎯 Tujuan

- Mengolah dan memahami data dalam jumlah besar secara sistematis.
- Mengidentifikasi pola dan karakteristik yang terdapat dalam data.
- Membangun model klasifikasi menggunakan Machine Learning.
- Membandingkan performa beberapa pendekatan Machine Learning.
- Mengevaluasi hasil model menggunakan beberapa metrik performa.
- Menghasilkan informasi yang dapat digunakan sebagai dasar analisis dan pengambilan keputusan berbasis data.

---

## 📊 Dataset

Dataset yang digunakan merupakan data kesehatan dengan **308.854 baris data** dan berbagai variabel, seperti:

- General Health
- Checkup
- Exercise
- Diabetes
- Age Category
- BMI
- Smoking History
- Alcohol Consumption
- Fruit Consumption
- Vegetable Consumption
- dan beberapa variabel lainnya.

Data kemudian dianalisis untuk memahami karakteristik serta hubungan antarvariabel sebelum digunakan dalam proses pemodelan.

---

## 🔎 Tahapan Project

### 1. Data Preparation

Melakukan persiapan dataset sebelum proses analisis, termasuk:

- Import dataset
- Pemeriksaan struktur data
- Pemeriksaan missing value
- Transformasi variabel
- Encoding data kategorikal
- Pemisahan variabel numerik, kategorikal, dan ordinal

### 2. Exploratory Data Analysis

Melakukan eksplorasi untuk memahami karakteristik data dan menemukan pola yang terdapat di dalam dataset.

### 3. Data Balancing

Karena terdapat ketidakseimbangan pada data target, digunakan pendekatan **BorderlineSMOTE** dan **Random Under Sampling** untuk membantu menghasilkan distribusi data yang lebih seimbang.

### 4. Machine Learning

Beberapa algoritma digunakan dan dibandingkan, antara lain:

- Random Forest
- CatBoost
- Voting Classifier

Model kemudian dilatih dan diuji menggunakan data yang telah diproses.

### 5. Model Evaluation

Evaluasi dilakukan menggunakan beberapa metrik, seperti:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC-AUC
